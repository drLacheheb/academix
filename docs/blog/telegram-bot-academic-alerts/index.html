Real-Time Academic Position Alerts & CV Ingestion via Telegram

Published by drLacheheb • 5 min read

Researchers are busy and rarely have time to manually browse multiple job boards every day. The Academix Telegram Bot bridges the gap between background crawlers and candidate researchers by delivering real-time alerts the moment a matching position is identified.

1. The Candidate Onboarding Flow

  1. Chat Initialization: The researcher begins a session with the bot via /start.
  2. CV Document Upload: The candidate uploads their CV in PDF format.
  3. Asynchronous Ingestion: The cv-parsing agent extracts the raw text layout, translation normalizes non-English text, refinement structures degrees and skills, and embedding-worker computes vector representations.

2. Push Notifications & Explanations

As new jobs are discovered by the 12 crawler agents, the matching engine continuously evaluates newly refined positions against all active candidate profiles.

When a match exceeds the candidate's threshold, a push alert is delivered directly to their Telegram chat with:

  • Position Title & Institution
  • Application Deadline
  • Match Score Percentage
  • Personalized LLM Match Explanation
  • Direct Application Link

3. Summary

By combining frictionless PDF ingestion with automated Telegram push alerts, Academix turns complex multi-portal academic searching into an effortless, personalized mobile experience.
