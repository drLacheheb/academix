Self-Hosting Academix with Docker, Ollama, and Structured Instructor Extraction

Published by drLacheheb • 5 min read

Academix is built from the ground up to be self-hosted on personal workstations, lab servers, or cloud VPS instances. All AI models (LLMs, neural translation, vector embeddings) run locally with zero third-party subscription fees.

1. Prerequisites

  • Docker & Docker Compose (v2.20+)
  • RAM: Minimum 8GB (16GB recommended when running Ollama LLMs)
  • Disk: ~10GB for Docker images and AI model weights

2. Quick Start Command

To clone and start the entire stack in CPU mode: 

git clone https://github.com/drLacheheb/academix.git
cd academix
cp .env.example .env
docker compose up --build -d

3. Structured Extraction with Instructor & Pydantic

Rather than relying on unstructured text outputs from LLMs, Academix connects to Ollama via the instructor library. This guarantees that all extracted academic qualifications strictly conform to validated Pydantic schemas:

  • education_level: Validated Enum (PHD, MASTER, BACHELOR)
  • prerequisite_degree_field: Normalized academic subject
  • required_skills & research_areas: Clean string lists
  • deadline: Standardized ISO 8601 date

4. NVIDIA GPU Acceleration

If your server is equipped with an NVIDIA GPU, enable hardware reservation by combining the GPU compose override: 

docker compose -f docker-compose.yml -f docker-compose.gpu.yml up --build -d
