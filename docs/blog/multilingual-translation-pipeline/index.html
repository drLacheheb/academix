Local Multilingual NMT: Sentence Splitting & CTranslate2 NLLB-200 for Scientific Offers

Published by drLacheheb • 6 min read

In European academic institutions, research openings are routinely posted in French, German, Spanish, or Dutch. However, candidate matching models and international applicants require uniform English representations to perform accurate semantic vector search.

Academix implements an entirely local, zero-cloud translation pipeline powered by Lingua, Sentencex, and CTranslate2 NLLB-200.

1. The Hybrid Document Challenge

Traditional translation workflows often classify the entire document as French or German and translate everything. However, academic listings are frequently bilingual: an institution may write the university boilerplate in French while keeping the technical research abstract in English.

Academix uses Sentencex to segment listings into individual sentences within each paragraph. Each sentence is evaluated independently by Lingua, which detects the exact language in sub-milliseconds. English sentences are preserved verbatim, preventing loss of technical precision.

2. Structure Preservation & Markdown Integrity

Scientific job descriptions contain complex markdown elements: headers (## Description), bulleted requirements (- PhD in Physics), URLs ([Apply Here](https://...)), and email contacts.

Before passing a sentence to NLLB-200, Academix masks markdown syntax and URLs with token placeholders, translates the raw semantic text, and seamlessly re-injects the formatting into the translated output.

3. Fast Local Inference with CTranslate2

By utilizing mijuanlo/nllb-200-distilled-600M-ct2-int8, the translation agent runs with an extremely small footprint:

  • Memory Usage: ~600MB RAM.
  • Latency: 50–150ms per sentence on standard CPU threads.
  • Language Coverage: 200 languages natively supported via dynamic FLORES-200 mapping.

4. Summary

This local architecture eliminates third-party translation API costs, preserves delicate academic markdown formatting, and ensures every job listing in the Academix database is available in clean English for downstream LLM extraction and vector matching.
